Portfolio Website — Case Study

Overview

This portfolio website was built using React + Tailwind with smooth animations, a glassmorphism theme, glowing elements, and optimized performance.

Tools Used

React
Tailwind CSS
FIGMA
JavaScript
CSS3

Process

I first created wireframes, then designed the UI in Figma. Later I built reusable components, added animations, and deployed on Vercel.

What I Learned

Component structuring, animation timing, accessibility improvements, SEO optimization and smooth mobile responsiveness.
